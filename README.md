# The Nexus Public Library

A curated, public mirror of selected reference material from **Alexandria's Library** — the private research archive maintained for [The Nexus](https://github.com/raceBannon99/The-Nexus), Rick Howard's AI-agent intelligence team. Essays, book reviews, fact sheets, and supporting images that are cleared for public viewing live here.

## What this is

This repo exists so that anything worth sharing publicly can be viewed and downloaded without exposing the private working archive it was drawn from. Items here are a deliberate, hand-picked subset — not everything in the private library is suitable for public release (some material is sourced from third parties without a redistribution license, or is otherwise internal-only), so publication to this repo is a one-way, reviewed decision, not an automatic mirror.

## How to use it

- **Browse**: every file renders directly in GitHub (Markdown, images).
- **Download**: use the "Download raw file" button on any file, or clone/download this whole repo as a ZIP via the green "Code" button.
- **Citing an item**: each entry in `INDEX.md` below states its author and rights holder — credit accordingly.

## Rights and reuse

Unless an individual file's entry in `INDEX.md` states otherwise, all rights are retained by the author or rights holder named there. This repo is provided for reference viewing and personal download, not as an open-source or freely-reusable dataset. If you want to reuse, republish, or build on something here beyond personal reference, reach out to confirm rights first.

## No public contributions

This repo does not accept external edits, issues, or pull requests — it is a one-way publication from the private library, maintained solely by its owner. Anyone can view and download; nobody but the owner can change or remove what's here.
